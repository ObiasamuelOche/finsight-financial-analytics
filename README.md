# Financial Performance Analysis Dashboard

## Project Overview
An interactive Power BI financial analytics project designed to
evaluate business performance, revenue, expenses and profitability.

## Objectives
- Analyse revenue and expenditure trends.
- Evaluate year-over-year financial performance.
- Identify major expense drivers.
- Compare departmental expenditure.
- Support data-driven business decisions.


## Data Sources

The project uses a structured financial dataset provided
as part of a Financial Analytics case study.

**Case Study Organization:** FinSight Distribution &
Consumer Products Ltd. (Fictional Nigerian FMCG company).

**Source File:** FinSight Financial Analytics Project.xlsx

**Primary Data Table:**
- FactFinancialTransactions

**Supporting Tables:**
- DimAccount
- DimDepartment
- DimBranch
- DimCostCentre

**Data Preparation:**
The dataset was imported into Power BI, transformed,
modelled and analysed to develop interactive financial
performance dashboards.

**Data Availability:**
The original case-study workbook is not included in
this public repository.
