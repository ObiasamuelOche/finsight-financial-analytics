# Financial Performance Analysis Dashboard

## Project Overview
An interactive Power BI financial analytics project designed to
evaluate business performance, revenue, expenses and profitability.

## Objectives
- Analyse revenue and expenditure trends.
- Evaluate year-over-year financial performance.
- Identify major expense drivers.
- Compare departmental expenditure.
- Support data-driven business decisions.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Visualization
- Financial Analysis

## Dashboard Pages

### 1. P&L Dashboard
Financial overview of revenue, expenses and profitability.

### 2. Executive Dashboard
High-level financial performance indicators and trends.

### 3. Departmental Analysis
Breakdown of expenditure by department and expense account.

## Key Insights
- Revenue growth and year-over-year comparisons.
- Expense growth and cost drivers.
- Departmental spending patterns.
- Profitability trends.
